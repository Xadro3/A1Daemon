# Changelog

## 0.5.0 — prototype

- Native Steam Claw tab without Decky, controller/keyboard navigation and standalone panel.
- Bounded sustained/boost package-power controls with readback and rollback on rejection.
- RGB effects, brightness, speed and controller-adjustable channels; discovery of both known kernel LED names.
- Live package/battery power, CPU/memory, temperatures, GPU clocks and render activity with explicit measurement limitations.
- Reversible A1M Wi-Fi D3cold and keyboard-wakeup workarounds.
- Native CachyOS package and graphical setup/repair/uninstall; explicit Bazzite/SteamOS installation boundary.
- Opt-in global settings persistence and restore after detected resume.
- Allowlisted support export, MIT license and documented security/support boundaries.

Release validation is recorded in docs/release-validation.md. This is a prototype prerelease, not a declaration that every sleep, game or Steam-update scenario is covered.
